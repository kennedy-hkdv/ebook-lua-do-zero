## 🎯 Para quem é

Para quem nunca programou, ou já programou em outra linguagem e quer aprender Lua. Tudo é explicado com exemplos curtos que você pode rodar e modificar.

## 🧰 Como praticar

1. Instale o Lua 5.4 ou use um executor online (procure por "Lua online" e escolha a versão 5.4).
2. Salve os exemplos em um arquivo `teste.lua` e rode com `lua teste.lua`.
3. Altere os valores, quebre o código de propósito e leia as mensagens de erro: é assim que se aprende.
